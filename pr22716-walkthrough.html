HMA 整页对齐与 Prefill 路径修复

为什么 78 层模型与 PCP > 1 下 Prefill 会掉回 Host 搬运慢路径？如何通过 binding.py 整页对齐打通原生 PA_BSND，并保留 Resident TND 作为安全兜底。

PR 标题：[Bugfix][HiSparse] Align HMA block stride to full MLA pages and support TND/PCP prefill fallback

固定分支：fix/hisparse-resident-prefill-tnd-pcp @ 7842b4718（base 44052241f）

改动范围：vllm_ascend/hisparse/binding.py、vllm_ascend/attention/sfa_hisparse.py 及 2 份 CPU 单测（test_hisparse_foundation_cpu.py、test_hisparse_pcp_cpu.py）

SECTION 01

问题根因：为什么之前 Prefill 掉回慢路径？

在 base 分支（44052241f）上，_try_c8_resident_prefill 原本只支持原生 PA_BSND 快路径。只要任一条件不满足，它就会直接 return None，使整个 Prefill 掉入 stage_prefill_rows（将 KV 从 Host 内存重新 H2D 搬运到临时缓冲）+ _c8_physical_attention（TND）慢路径。

三个把 Prefill 踢出 PA_BSND 的根因：
  1. HMA 共享池 remainder != 0：78 层模型与 Indexer 共享物理 slab 时，binding.py 此前只按单行粒度（656 B）声明 block_stride_alignment，且未向共池的 AscendSFAIndexerCacheSpec 透传整页对齐。导致 Core 算出的 attention_block_stride 不能被 block_size = 128 整除（remainder != 0），PA_BSND 无法按页步长直接寻址。
  2. PCP > 1 的 padding 门禁误杀：开启 PCP=2 后，query 与 logical_topk 尾部带有 PCP padding 行（query.shape[0] > num_prefill_tokens），原代码用严格相等 query.shape[0] == num_prefill_tokens 拦截，直接导致 PCP=2 全程无法进入 resident prefill。
  3. BF16 路径未复用 paged SFA：非 C8（enable_sparse_sfa_c8=False）场景在 stage_prefill_rows 后还要做一次 sort + pack_attention_rows 重打包，未直接复用 super()._execute_sparse_flash_attention_process 的 PA_BSND 分页能力。

SECTION 03

核心改动一：binding.py 整页对齐（含中文注释）

vLLM Core 的 get_hisparse_kv_cache_groups() 在构建合成的 HiSparseResidentSpec / HiSparseHotSpec 时，会丢弃源 Spec 的 block_stride_alignment。因此在 align_hisparse_indexer_specs 中，必须同时给共池的 AscendSFAIndexerCacheSpec 和合成 Spec 声明 spec.block_size * packed_row_bytes 的整页对齐。

vllm_ascend/hisparse/binding.py — align_hisparse_indexer_specs（已加详细中文注释）
def align_hisparse_indexer_specs(
    specs: dict[str, KVCacheSpec],
    *,
    packed_row_bytes: int | None = None,
) -> dict[str, KVCacheSpec]:
    """向 vLLM Core 的 shared-slab 规划器声明整页对齐约束。"""
    if packed_row_bytes is not None and packed_row_bytes <= 0:
        raise ValueError("HiSparse packed row width must be positive")
    aligned = {}
    for name, spec in specs.items():
        alignment = spec.get_block_stride_alignment()
        updates = {}
        if isinstance(spec, AscendSFAIndexerCacheSpec):
            _validate_indexer_spec(spec)
            if spec.cache_sparse_li_c8:
                # C8 模式下 Indexer 的 K 与 scale 在页内各自连续存放，需预留两者空间
                updates["page_size_padded"] = max(spec.page_size_bytes, spec.page_size_padded or 0)
                alignment = math.lcm(alignment, spec.head_size, torch.float32.itemsize)
            else:
                alignment = math.lcm(alignment, spec.page_size_bytes)
            if packed_row_bytes is not None:
                # [PR #22716 关键修复 1]：
                # Ascend PA_BSND 要求共享 slab 的 block_stride 对齐到整页（block_size * packed_row_bytes，
                # 例如 128 * 656 = 83,968 B）。因为 Core 的 get_hisparse_kv_cache_groups() 重建
                # HiSparseResidentSpec/HotSpec 时会丢掉 block_stride_alignment，所以必须通过
                # 同池共用的 AscendSFAIndexerCacheSpec 把整页对齐透传给 Core。
                alignment = math.lcm(alignment, spec.block_size * packed_row_bytes)
        elif packed_row_bytes is not None and isinstance(spec, (HiSparseResidentSpec, HiSparseHotSpec)):
            # [PR #22716 关键修复 2]：
            # 对合成的 Resident/Hot Spec 同样把对齐粒度从 packed_row_bytes（单行）提升到整页，
            # 让 Core 在计算物理块大小时直接分配整页倍数（remainder == 0）。
            alignment = math.lcm(alignment, spec.block_size * packed_row_bytes)
        if alignment != spec.get_block_stride_alignment():
            updates["block_stride_alignment"] = alignment
        aligned[name] = replace(spec, **updates) if updates else spec
    return aligned

核心改动二：sfa_hisparse.py 分流、PCP 切片与兜底（含中文注释）

在 sfa_hisparse.py 中，本 PR 完成了三项协同改动：① 放宽 PCP padding 长度门禁并做有效行切片；② 在 PA_BSND 条件不满足时保留 Resident TND 兜底且用 info_once 明确区分两条路径；③ BF16 stage_prefill_rows 路径同样复用 paged SFA。

vllm_ascend/attention/sfa_hisparse.py — _try_c8_resident_prefill 与 BF16 分支（已加详细中文注释）
    def _try_c8_resident_prefill(self, query, query_rope, logical_topk, metadata, query_ends, key_lengths):
        num_decodes = metadata.num_decodes
        num_decode_tokens = metadata.num_decode_tokens
        num_prefill_tokens = metadata.num_actual_tokens - num_decode_tokens
        # [PR #22716 修复 3]：开启 PCP 时 query/query_rope/logical_topk 尾部存在 padding，
        # 形状会大于等于有效 prefill token 数；原代码写 "==" 会直接误杀 PCP 场景。
        if (
            not self.enable_sparse_sfa_c8
            or metadata.hisparse_for_capture
            or query_rope is None
            or num_prefill_tokens <= 0
            or metadata.num_reqs != num_decodes + metadata.num_prefills
            or query.shape[0] < num_prefill_tokens
            or query_rope.shape[0] < num_prefill_tokens
            or logical_topk.shape[0] < num_prefill_tokens
        ):
            return None
        cache = self.hisparse_cache
        view = cache.view
        state_indices = cache.runtime.request_state_indices
        if (
            not cache.all_context_pages_resident
            or cache.dummy_batch
            or cache.draft_layer
            or view is None
            or cache.block_table is None
            or state_indices is None
            or state_indices.numel() < metadata.num_reqs
            or query_ends.shape != (metadata.num_reqs,)
            or key_lengths.shape != (metadata.num_reqs,)
        ):
            return None
        if (
            get_forward_context().cudagraph_runtime_mode != CUDAGraphMode.NONE
            or torch.npu.is_current_stream_capturing()
        ):
            return None

        # 裁掉 PCP 尾部 padding，只把真实有效 token 送入算子
        query = query[:num_prefill_tokens]
        query_rope = query_rope[:num_prefill_tokens]
        logical_topk = logical_topk[:num_prefill_tokens]

        # 计算每块对应多少个完整 MLA 页（page_stride）以及余数（remainder）
        page_stride, remainder = divmod(view.attention_block_stride, view.block_size)
        storage = view.attention_cache
        # [注意]：这里必须用非原地操作，避免后面若走 TND 兜底时污染原始 block_table
        table = cache.block_table.index_select(0, state_indices[num_decodes : metadata.num_reqs].to(torch.long))

        # 路径 ①：PA_BSND 原生快路径（依赖 binding.py 整页对齐，正常情况下 remainder == 0 必命中）
        if (
            remainder == 0
            and page_stride >= 1
            and storage.is_contiguous()
            and view.cache.stride(0) == view.attention_block_stride * view.cache.stride(1)
            and storage.size(0) > (view.cache.size(0) - 1) * page_stride
        ):
            table = table.clamp_min(0).mul(page_stride)
            if num_decodes:
                query_ends = query_ends[num_decodes:] - num_decode_tokens
                key_lengths = key_lengths[num_decodes:]
            output = super()._execute_sparse_flash_attention_process(
                query,
                query_rope,
                (storage.unsqueeze(2),),
                logical_topk.unsqueeze(1),
                metadata,
                query_ends,
                key_lengths,
                block_table=table,
            )
            logger.info_once(
                "[hisparse] Resident paged Prefill active (PA_BSND): mixed=%s",
                bool(num_decodes),
                scope="process",
            )
            return output

        # 路径 ②：Resident TND 兜底路径（仅当外部绕过 binding.py 导致 remainder != 0 时触发）
        # 直接在 NPU Resident 上做逐 token 物理偏移映射，至少避免退化回 Host H2D 搬运。
        resident_cache = view.cache
        req_id_per_token = metadata.req_id_per_token
        if (
            resident_cache.ndim != 3
            or resident_cache.dtype not in (torch.int8, torch.float8_e4m3fn)
            or resident_cache.shape[-1] != C8_ROW_BYTES
            or view.block_size <= 0
            or view.attention_block_stride < view.block_size
            or resident_cache.stride(1) != C8_ROW_BYTES
            or resident_cache.stride(2) != 1
            or resident_cache.stride(0) != view.attention_block_stride * resident_cache.stride(1)
            or req_id_per_token is None
            or req_id_per_token.numel() < num_decode_tokens + num_prefill_tokens
            or table.shape[1] <= 0
            or logical_topk.ndim != 2
            or logical_topk.shape[1] <= 0
            or logical_topk.shape[1] % 128
        ):
            return None

        req_ids = (
            (req_id_per_token[num_decode_tokens : num_decode_tokens + num_prefill_tokens] - num_decodes)
            .clamp(0, table.shape[0] - 1)
            .to(torch.long)
        )
        safe_logical = logical_topk.clamp_min(0).to(torch.long)
        block_ids = safe_logical // view.block_size
        offsets = safe_logical % view.block_size
        in_bounds = (logical_topk >= 0) & (block_ids < table.shape[1])
        req_tables = table[req_ids]
        phys_blocks = torch.gather(req_tables, 1, block_ids.clamp_max(table.shape[1] - 1)).to(torch.long)
        valid = in_bounds & (phys_blocks >= 0)
        mapped = torch.where(valid, phys_blocks.clamp_min(0) * view.attention_block_stride + offsets, -1).to(
            torch.int32
        )
        output = self._c8_physical_attention(
            query,
            query_rope,
            resident_cache,
            compact_c8_indices(mapped),
            indices_are_mapped=True,
        )
        logger.info_once(
            "[hisparse] Resident paged Prefill fallback active (TND): mixed=%s",
            bool(num_decodes),
            scope="process",
        )
        return output

SECTION 05

延伸理解：为什么 A5 PA_BSND 仍比 OFF 慢 ~1.2s（HostMirror 掩盖边界）

打通 PA_BSND 后，A5 32K/128 C=1 TTFT 从 11.89s 降到 6.19s，但对比 OFF（5.00s）仍有约 +1.20s（+24%）差距。结合 host_mirror.py 与 A5 Profiling 可知，这主要来自 Prefill 步末同步等 D2H 尾巴：

  • 层间一直有并行掩盖：第 1~78 层每层算完调 submit_layer_mirror，后台 DMA 流与后续层计算并行。
  • 但步末不允许跨 chunk 异步：因 Scheduler 在两步之间可能释放/驱逐/重分配物理块，所有在途 D2H 必须在 finalize_step() 前写完落盘。
  • 只有纯 Decode 吃到了 draft defer：host_mirror.py:169 显式限定 not input_batch.has_prefill 且无 padding 时才把同步推迟到 MTP/Draft 之后；A5 TP4 × PCP2 计算太快、单卡 D2H 流量大，78 层算完时 DMA 还剩约 1.3s 尾巴没搬完，只能在 finish_forward() 当场等完。
